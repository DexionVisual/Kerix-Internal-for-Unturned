# Kerix.zyx

![status](https://img.shields.io/badge/STATUS-UNDETECTED-brightgreen?style=for-the-badge)

внутренний чит для unturned

## из чего состоит

проект делится на две части:

- `loader/` - нативная dll (c). сама по себе ничего не умеет, ее задача -
  пробиться в mono рантайм игры (root domain), найти главный поток и запустить
  `Kerix.Loader.Init()` уже в управляемом коде. сделано через хук очереди
  сообщений винды, поэтому юнити апи не крашится от чужого потока

- `cheat/` - сам чит (c#). компонент вешается на gameObject и дальше живет
  в игре: esp, аимбот, меню, конфиги

`Vault.dll` в `cheat/libs/` - это Harmony под другим именем, нужна чтобы патчить
стрельбу и отдачу изнутри.

## что умеет

**aimbot**
- vector aim: сводит сам прицел, fov круг, сглаживание от мгновенного до
  плавного, цель на голову или грудь
- silent aim: пули летят в цель, прицел остается на месте. работает через
  правку BulletInfo после создания, до баллистики
- контроль отдачи: гасит кик на заданный процент, можно отдельно от аимбота
- все настройки в отдельных подтабах

**esp**
- игроки: бокс, хп, ник, дистанция, линии, высота бокса подстраивается под позу
- зомби (мега/босс/радиактивный отдельным цветом)
- машины + hp и топливо
- предметы на земле, цвет по редкости
- фпс каунтер

**misc**
- радар (игроки, тиммейты другим цветом, техника, дальность настраивается)
- хитмаркер
- фаст перезарядка
- техника не жрет бензин

**прочее**
- конфиги в .krx файл рядом с dll (сейв/лоад/сброс в вкладке настроек)

## сборка

нужна visual studio (с++ тулсет + .net 4.8 targeting pack), больше ничего.

    Kerix\build.bat

скрипт сам скомпилит обе части и кинет Kerix.dll + Vault.dll в корень игры.

## использование

1. install: Kerix.dll и Vault.dll должны лежать рядом с Unturned.exe
2. запустить игру (одиночка / сервер без battleye)
3. заинжектить KerixLoader.dll в Unturned.exe любым инжектором
4. INSERT - меню, END - вкл/выкл esp

не работает - в папке игры лежат kerix_loader.log и kerix_cheat.log,
там написано на каком шаге что случилось.

## структура

    loader/bootstrap.c      нативный лоадер
    cheat/src/*.cs          весь чит
    cheat/libs/Vault.dll    harmony
    build.bat               собрать все
